Mark Job Application Agent

Personal job-search and application-preparation automation for engineering roles in Germany.

What the application does

Mark is a private tool operated by its account owner. It helps discover relevant engineering jobs, maintain a job-application tracker, prepare application documents, and recognize job-application updates. It is not a public recruiting platform.

Why it connects to Google

  • Google Sheets: Reads tracker data and approved search rules, then records newly discovered vacancies and relevant application status updates.
  • Gmail: Reads messages to identify job-application updates and authorized email verification requests, and may send notifications.
  • Google Drive: Synchronizes the owner's approved résumé, cover letters, and generated application packages when configured.

Private employment records, application credentials, and personal files are not displayed on this informational site. Actual automation runs on a privately operated Oracle Cloud server and n8n workflows, not in this website.
